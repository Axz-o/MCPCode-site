We updated the **v0.1.0-alpha** Windows build with smoother onboarding, guided setup, and more reliable long-running ChatGPT sessions.

## What changed

### Meet Mico onboarding
First-time launches now start with a brief introduction featuring Mico, local profile naming (with live avatar initials), and a smooth transition into the main Aurora workspace. You can replay it anytime from **`?` → Replay introduction**.

### Quick Setup: Connect ChatGPT
**Settings → Connections** now includes a 4-step **Quick Setup** checklist that tracks **Local MCP** and **Secure Tunnel** status live and opens OpenAI Tunnels, ChatGPT Connectors, and the full illustrated guide directly in your browser.

### Longer MCP sessions & in-app update checks
- Increased the Local MCP session limit (`1000` sessions) and idle timeout (`30 minutes`) so ChatGPT Web sessions stay responsive after pauses.
- Added background and manual update checks inside the **`?`** menu.
